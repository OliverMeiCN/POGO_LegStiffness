POGO was developed using R to automate leg stiffness estimation from synchronized three-dimensional motion-capture and force-platform data. 
The workflow integrates C3D file processing, kinematic and kinetic data extraction, biomechanical event detection, force-displacement parameter extraction, leg stiffness calculation, and standardized result export within a unified framework.

Examples using POGO for quick and automatic calculation of leg stiffness during running and CMJ landing are presented.
